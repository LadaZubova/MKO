Актуальность

Абляционная защита, применяемая на большинстве современных спускаемых аппаратов, необратимо теряет материал при каждом спуске. После каждой миссии требуется полная замена теплозащитного экрана — это увеличивает стоимость и время межполётной подготовки.

Фазопереходные материалы (ФПМ) способны сохранять массу при циклах «плавление–затвердевание», что делает их перспективными для создания многоразовых теплозащитных систем. Однако систематическое сравнение абляции и ФПМ при одинаковых тепловых нагрузках в открытой литературе представлено ограниченно.

Настоящая работа восполняет этот пробел, предлагая методику сравнения для ранних этапов проектирования.

Цель и задачи

Количественно сравнить абляционную и фазопереходную термозащиту по массе и толщине; обосновать гибридную схему для многоразовых спускаемых аппаратов.

  1. Рассчитать тепловую энергию, действующую на экран
  2. Определить массу и толщину слоя для ФПМ и аблятора
  3. Провести нестационарный тепловой расчёт
  4. Оценить экономическую эффективность гибридной схемы
  5. Рассмотреть применение для Марса и Титана

Теплозащита — не универсальная задача, а комплексная проблема, требующая индивидуального подхода для каждой планеты.

Выводы

  1. Чистый ФПМ непригоден для теплозащиты: масса 4,45–5,65 т, толщина 0,95–2,25 м. Поверхность раскаляется до 1900 °C.
  2. Абляционная защита эффективна по массе в 80–100 раз, но одноразова и создаёт техногенную нагрузку.
  3. Гибридная схема «аблятор + ФПМ-подслой» — оптимальное решение. Снижение толщины аблятора на 30–50%.
  4. Глауберова соль предпочтительнее парафина: объёмная плотность энергии в 2,4 раза выше.
  5. Экономическая выгода гибрида — около 1,1 млрд руб. за 10 полётов.
  6. Парашютная система: диаметр купола +31%, масса +72%.
  7. Методика применима для Марса и Титана, но требует адаптации под условия каждой атмосферы.

Перспективы развития

  • Уточнение нестационарного расчёта с учётом разложения ФПМ и уноса массы
  • Численное моделирование в ANSYS и COMSOL
  • Экспериментальные испытания гибридной системы
  • Исследование альтернативных фазопереходных материалов
  • Разработка барьерного слоя и системы охлаждения
  • Оценка ресурса ФПМ при многократных циклах
  • Расчёт теплозащиты для Марса и Титана с помощью 3D-CFD
